# SGOE · I.E. Fe y Alegría N.° 37

Website único para los trabajos integradores del curso **Sistema de Gestión para Organizaciones Educativas** (UPSJB, 2026).

## Portada para entregar

**https://pansitozzz.github.io/fe-y-alegria-37-sgoe/**

La portada tiene **solo dos opciones de acceso**:

1. **Trabajo Integrador 1 · Semana 04:** [semana-04.html](https://pansitozzz.github.io/fe-y-alegria-37-sgoe/semana-04.html)
2. **Trabajo Integrador 2 · Semana 08:** [integrador-2.html](https://pansitozzz.github.io/fe-y-alegria-37-sgoe/integrador-2.html)

Cada trabajo ofrece su propio índice de navegación. No existen enlaces directos entre las semanas: el retorno siempre es a la portada para volver a elegir.

## Identidad visual

Las tres páginas HTML usan **una sola hoja de estilos: `assets/site.css`**. Fondo carbón, rojo institucional, blanco y tonos de gris. Se reutilizan los mismos encabezados, pies, botones, tarjetas y estructuras. No hay temas o paletas independientes para las semanas.

## Semana 04 · Trabajo Integrador 1

Organización educativa, nivel y contextualización geográfica, misión y visión, matriz de necesidades, partes interesadas, entradas/salidas, mapa general y conclusiones. Las interacciones del diagnóstico se encuentran en `assets/app.js`.

## Semana 08 · Trabajo Integrador 2

Contexto, inventario (2 estratégicos, 4 misionales, 4 de soporte), mapa de procesos de nivel 0, 10 fichas completas de caracterización, implementación y fuentes. Cada ficha incorpora responsable, objetivo, alcance, PHVA, proveedores internos y externos, entradas, actividades, salidas, clientes, requisitos, recursos, indicador y meta, riesgos y seguimiento.

Los datos de las diez fichas se encuentran en `assets/integrador2-data-a.js` y `assets/integrador2-data-b.js`; la interacción se maneja en `assets/integrador2.js`.

## Publicación

Sitio estático HTML/CSS/JS, sin compilación. GitHub Pages: rama `main`, carpeta `/`. La URL de entrega académica es la portada del website, no la página del código ni un PDF.

**Nota:** La propuesta académica está sujeta a validación institucional. Las metas no constituyen datos observados ni las fichas cuentan con aprobación de la institución.
