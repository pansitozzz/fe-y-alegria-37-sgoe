El sitio es estático, sin dependencias externas de desarrollo. GitHub Pages puede servir directamente la rama `main`, carpeta raíz (`/`). La página `integrador-2.html` se enlaza desde `index.html`. Las fichas se encuentran en `assets/integrador2-data-a.js` y `assets/integrador2-data-b.js` y se presentan mediante `assets/integrador2.js`.
